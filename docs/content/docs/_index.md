Sprout looks bigger than it actually is. For what it does, it's tiny. A full working app with robust release plumbing, yet smaller than a lot of CLI frameworks by themselves.. It can look big due to Windows / Linux impl files and tests. To use Sprout you probably don't need to understand those parts, but if you do, these docs should help you understand which.
